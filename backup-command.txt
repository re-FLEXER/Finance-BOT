====================================================================
               GIT & BACKUP CHEATSHEET | FINANCE BOT
====================================================================

[1] РУТИННИЙ СИНХРОН (Перед початком роботи на будь-якому ПК)
--------------------------------------------------------------------
git pull origin main
> Затягує та об'єднує останні зміни з GitHub у ваш локальний код.


[2] РОБОЧИЙ ЦИКЛ (Збереження та відправка нових фіч/фіксів)
--------------------------------------------------------------------
git status
> Перевіряє список змінених та нових файлів.

git add .
> Індексує (підготовлює) усі зміни до збереження.

git commit -m "Опис ваших змін"
> Створює точний знімок-копію коду з текстовим коментарем.

git push origin main
> Відправляє нові коміти на GitHub у головну гілку main.


[3] ОНОВЛЕННЯ БЕКАПУ (Виконувати ТІЛЬКИ після перевірки стабільності)
--------------------------------------------------------------------
git tag -f -a v1.0-working -m "Робоча версія V1.0"
> Перезаписує контрольний тег v1.0-working на найсвіжіший коміт.

git push origin --tags -f
> Примусово відправляє оновлений тег-бекап на GitHub.


[4] КОНТРОЛЬ СТАНУ ТА ЛОГИ
--------------------------------------------------------------------
git log --oneline -n 5
> Показує останні 5 комітів та поточну позицію тегу v1.0-working.


[5] РОЗШИФРОВКА ПРАПОРЦІВ (OPTIONS)
--------------------------------------------------------------------
  -m      : Message (Додає текстовий коментар)
  -f      : Force (Примусово перезаписує дані)
  -a      : Annotated (Створює повноцінний анотований тег із датою)
  --tags  : Надсилає створені мітки-бекапи на віддалений сервер
