Основний порядок команд для оновлення бекапу:

git add .

Опис: Фіксує всі змінені та нові файли у вашому проєкті й підготовлює їх до збереження.

git commit -m "Опис ваших змін"

Опис: Створює точну "знімок-копію" (коміт) збереженого коду з вашим текстовим коментарем.

git push origin main

Опис: Відправляє всі нові коміти з вашого ПК на GitHub у головну гілку main.

git tag -f -a v1.0-working -m "Робоча версія V1.0 з усіма фіксами"

Опис: Перевешує спеціальну контрольну мітку (тег) v1.0-working на останній свіжий коміт. Прапорець -f оновлює вже існуючий тег, а -a дозволяє додати опис.

git push origin --tags -f

Опис: Примусово надсилає оновлений тег-бекап на GitHub, щоб версія в хмарі збігалася з вашою локальною міткою.

Допоміжні команди для перевірки стану:

git status — показує, які файли були змінені та чи є незакоммічені правки.

git log --oneline -n 5 — виводить останні 5 комітів і показує, де зараз знаходиться ваш тег v1.0-working.
