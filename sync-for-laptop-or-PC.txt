===================================================
📋 РУТИНА СИНХРОНІЗАЦІЇ: РОБОЧИЙ НОУТ -> GITHUB
===================================================

1. ПІДТЯГНУТИ СВІЖИЙ КОД З ЗМІНАМИ З ДОМУ
   git pull origin main
   (Оновлює index.js, schema.prisma та інші файли)

2. ВСТАНОВИТИ НОВІ ПАКЕТИ ТА БІБЛІОТЕКИ
   npm install
   (Перевіряє package.json і завантажує нові модулі, якщо вони додавалися)

3. ОНОВИТИ КЛІЄНТ PRISMA ТА ТИПИ БАЗИ
   npx prisma generate
   (Синхронізує код Prisma у node_modules із актуальною schema.prisma)

4. ТЕСТОВИЙ ЗАПУСК ЛОКАЛЬНО (ЗА ПОТРЕБИ)
   node index.js
   (Запускає локальний сервер для тестування перед деплоєм)

---------------------------------------------------
💡 ПРИМІТКА: Якщо додавалися нові ключі в .env удома,
перевірте, щоб файл .env на ноуті мав ті самі значення.
